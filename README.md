# 감가상각비 계산

고정자산명을 입력하면 **분류·내용연수·상각방법을 법인세법 기준으로 자동 판단**해 당기 감가상각비와 연도별 상각내역을 계산하는 웹 프로그램입니다. 설치 없이 브라우저에서 바로 동작합니다.

## 사용 방법

1. `index.html`을 더블클릭해 크롬 또는 엣지에서 엽니다.
2. **기본 설정**: 회사명, 계산할 사업연도, 사업연도 시작월을 입력합니다.
3. **고정자산 입력**: 자산을 직접 입력하거나, 엑셀 파일을 불러오거나(버튼 또는 끌어다 놓기), 엑셀에서 복사해 붙여넣습니다.
4. **계산내역**: 당기 상각비가 계산되고, 행을 누르면 연도별 상각내역이 펼쳐집니다. **엑셀로 저장**으로 내려받을 수 있습니다.

자산목록 엑셀 형식은 `감가상각_샘플데이터.xlsx`를 참고하세요. (열: 자산명 · 취득일 · 취득가액 · 전기말 상각누계액)

## 주요 기능

- 자산명 키워드로 분류 자동 판단 (건물 구조별, 구축물, 기계장치, 차량운반구, 업무용승용차, 비품, 무형자산, 토지 등)
- 정액법 / 정률법, 기준내용연수 및 선택 범위(±25%)
- 사업연도 중 취득 시 월할 계산 (1개월 미만은 1개월)
- 정률법 5% 잔존가액 가산, 비망가액(취득가액 5%와 1,000원 중 적은 금액)
- 업무용승용차 정액법 5년, 연 800만원 한도초과액 표시
- 100만원 이하 즉시상각 가능 자산 표시
- 엑셀(.xlsx / CSV) 불러오기, 서식 있는 엑셀(.xlsx) 저장, 인쇄

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `style.css` | 디자인 |
| `app.js` | 자산 분류 판단과 감가상각 계산 |
| `xlsx.js` | 엑셀 파일 읽기·쓰기 (외부 라이브러리 없음) |
| `감가상각_샘플데이터.xlsx` | 가상 회사의 예시 자산목록 |

네 개의 프로그램 파일(`index.html`, `style.css`, `app.js`, `xlsx.js`)은 항상 같은 폴더에 있어야 합니다.

## 주의

자동 판단은 자산명 키워드에 기반한 보조 도구입니다. 기계장치의 업종별 내용연수(시행규칙 별표6), 건물·구축물 구조, 신고내용연수, 업무용승용차 해당 여부는 반드시 직접 확인하세요. 상각률은 시행규칙 별표4 산식으로 계산하므로 별표4와 대조를 권장합니다.
